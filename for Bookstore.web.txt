- REST Services

For a bookstore web application, a REST service is the backend part that lets the frontend (React, mobile app, website, etc.) communicate with the bookstore data using HTTP requests.

Think of it like this:

Frontend = bookstore cashier/customer interface
REST API = employee who receives requests
Database = warehouse storing books

Example: Bookstore
Suppose your database contains:
{
"id": 1,
"title": "Spring Boot in Action",
"author": "Craig Walls",
"price": 39.90
}

1. Get all books
Frontend sends: GET /api/books
REST service returns:

In Spring Boot, you would typically create a REST controller:
@RestController
@RequestMapping("/api/books")
public class BookRestController {
 
@Autowired
private BookRepository repository;
 
@GetMapping
public Iterable<Book> getBooks() {
return repository.findAll();
}
 
@GetMapping("/{id}")
public Book getBook(@PathVariable Long id) {
return repository.findById(id).orElse(null);
}
 
@PostMapping
public Book addBook(@RequestBody Book book) {
return repository.save(book);
}
 
@PutMapping("/{id}")
public Book updateBook(@RequestBody Book book) {
return repository.save(book);
}
 
@DeleteMapping("/{id}")
public void deleteBook(@PathVariable Long id) {
repository.deleteById(id);
}
}
